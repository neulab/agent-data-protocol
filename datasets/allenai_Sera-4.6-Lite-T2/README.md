# allenai/Sera-4.6-Lite-T2 Dataset

## Description

Sera-4.6-Lite-T2 is a software engineering agent trajectory dataset from the `casey-martin/agent-trajectories` collection. It contains trajectories generated from the second rollout of SVG on 121 SWE-smith codebases using GLM-4.6 as the teacher model. Each trajectory records a coding task, OpenHands-style tool use, command output, generated rollout patch, and target patch metadata.

The dataset focuses on:
- Software engineering bug-fix and code-editing trajectories
- OpenHands-style interactions with bash and file editing tools
- SWE-smith repository tasks with rollout and target patch metadata
- Research and educational use cases for training coding agents

## Dataset Information

**Source URL**: https://huggingface.co/datasets/allenai/Sera-4.6-Lite-T2

**License**: Open Data Commons Attribution License v1.0 (ODC-By)

**Size/Split Used**: 36,083 trajectories from the single published JSONL file (`sera-4.6-lite-t2_36083_string_enriched.jsonl`). The checked-in sample files use the first 3 trajectories in source order.

## Raw Schema

The raw dataset contains these top-level fields:
- `messages`: JSON-encoded list of chat/tool messages
- `instance_id`: trajectory identifier
- `rollout_patch`: patch generated by the rollout
- `func_name`: sampled function name
- `func_path`: path to the sampled function
- `problem_statement`: task statement supplied to the model
- `target_patch`: ground-truth patch metadata
- `docker_image`: Docker image used for the trajectory

## Conversion Notes

- System prompts are omitted from standardized content and preserved in `details`.
- User messages become `TextObservation(source="user")`.
- Tool observations become `TextObservation(source="environment")` with a leading `OBSERVATION:` prefix removed when present.
- `bash` tool calls become `CodeAction(language="bash")`.
- `submit` tool calls are represented as bash `CodeAction` with content `submit` because the raw environment describes it as the submit command.
- `str_replace_editor` tool calls become `ApiAction(function="str_replace_editor")`.
