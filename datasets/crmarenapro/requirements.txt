# Dependencies for REGENERATING CRMArena-Pro rollouts (the raw agent
# trajectories) — NOT for the ADP conversion scripts in this directory.
# extract_raw.py, schema_raw.py, raw_to_atif.py, and atif_to_std.py rely only on
# the Python standard library plus the shared agent-data-protocol dependencies.
#
# Rollouts are produced by running the CRMArena ReAct agent
# (https://github.com/SalesforceAIResearch/CRMArena) against the CRMArena-Pro
# b2b / b2c Salesforce sandboxes via its run_tasks.py
# (--agent_strategy react --org_type b2b|b2c). Install these into that runtime
# environment, e.g.:
#
#   pip install -r datasets/crmarenapro/requirements.txt
#
# Versions match CRMArena's pinned requirements for the packages specific to the
# rollout harness. Transitive core libraries (pydantic, numpy, requests) are
# intentionally left unpinned so installing this file does not downgrade the
# agent-data-protocol environment (which requires a newer pydantic).
#
# KNOWN CONFLICT: together==1.3.1 pins pillow<11 and rich<14, but agent-data-protocol's
# openhands-sdk (used by the openhands_sdk SFT converter) needs pillow>=12.1.1 and
# rich>=14. `together` is only imported by CRMArena's chat_agent for the together_ai
# provider (never called on the OpenAI/custom-endpoint path) and imports fine with
# newer pillow/rich, so the pin is safe to override. After installing this file into
# an env that also has openhands-sdk, run:
#   pip install 'pillow>=12.1.1' 'rich>=14.0.0'
# (pip will print a harmless "together ... incompatible" warning that can be ignored.)
