# Mind2Web (Multimodal)

Multimodal variant of [Mind2Web](https://osu-nlp-group.github.io/Mind2Web/) with per-action screenshots. Uses the same underlying trajectories as `mind2web/` but sourced from `osunlp/Multimodal-Mind2Web` which adds screenshot observations and restructures data as per-action rows.

- **Paper**: [Mind2Web: Towards a Generalist Agent for the Web](https://arxiv.org/abs/2306.06070)
- **Source**: [osunlp/Multimodal-Mind2Web](https://huggingface.co/datasets/osunlp/Multimodal-Mind2Web)
- **License**: OpenRAIL
- **Size**: ~1,296 trajectories, ~6 actions/trajectory average
- **Domains**: 31 domains, 137 websites (real websites, not simulated)
- **Actions**: CLICK, TYPE, SELECT (with BrowserGym IDs)
- **Screenshots**: SoM-annotated (generated via BrowserGym during standardization)

## Pipeline

### 1. Install dependencies

```bash
pip install -r datasets/mind2web_multimodal/requirements.txt
playwright install chromium
```

### 2. Extract raw data

Downloads from `osunlp/Multimodal-Mind2Web` on HuggingFace. Groups per-action rows into per-trajectory JSONL, drops neg_candidates and raw_html to reduce size.

```bash
# Sample (5 trajectories):
python datasets/mind2web_multimodal/extract_raw.py --limit=5 | python scripts/jsonl_to_json.py > datasets/mind2web_multimodal/sample_raw.json

# Full dataset with original screenshots:
python datasets/mind2web_multimodal/extract_raw.py --output-dir=datasets/mind2web --download-images > mind2web_raw.jsonl

# Stats only:
python datasets/mind2web_multimodal/extract_raw.py --stats-only
```

### 3. Convert to standardized format

Renders cleaned_html in BrowserGym, generates axtrees with BIDs, resolves element targets, and produces SoM-annotated screenshots. Requires Chromium.

```bash
export PYTHONPATH=$(pwd):$PYTHONPATH
cat datasets/mind2web_multimodal/sample_raw.json | python scripts/json_to_jsonl.py | \
    python datasets/mind2web_multimodal/raw_to_standardized.py --filter-som | \
    python scripts/jsonl_to_json.py > datasets/mind2web_multimodal/sample_std.json
```

### 4. Convert to SFT format

```bash
export MY_DATASET=mind2web_multimodal
cat datasets/mind2web_multimodal/sample_std.json | python scripts/json_to_jsonl.py | \
    python agents/openhands/std_to_sft.py --is_web=yes --api_env=browser | \
    python scripts/jsonl_to_json.py > datasets/mind2web_multimodal/sample_sft/sample_sft_openhands.json
```

## Data format notes

- **Element targeting**: Uses BrowserGym IDs (BIDs) resolved from backend_node_id attributes in cleaned_html via axtree pre-generation.
- **Axtree**: SoM-filtered (interactive elements only, ~27 lines vs ~3400 unfiltered). BIDs in the axtree match the SoM screenshot labels.
- **Screenshots**: Generated by BrowserGym from rendered cleaned_html with SoM overlay (BID labels on interactive elements). Original Mind2Web full-page JPEGs can be saved separately via `--download-images`.
- **Empty pos_candidates**: ~5.8% of actions have no target element (mostly SVG icon clicks). These are skipped during standardization.
