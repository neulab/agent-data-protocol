# SWE-Gym/MoatlessTools-Sampled-Trajectories

 [SWE-Gym](https://github.com/SWE-Gym/SWE-Gym) is an environment for training SWE agents, with 2.4K real tasks from 11 Python repos & a Lite split of 234 instances. SWE-Gym combines real-world Python tasks, repository context, executable environments, and test verification to train agents for solving software engineering problems.

[SWE-Gym/MoatlessTools-Sampled-Trajectories](https://huggingface.co/datasets/SWE-Gym/MoatlessTools-Sampled-Trajectories) is a dataset of trajectories generated using [MoatlessTools agents](https://github.com/aorwall/moatless-tools)

For more details, check the paper [Training Software Engineering Agents and Verifiers with SWE-Gym](https://arxiv.org/pdf/2412.21139).
