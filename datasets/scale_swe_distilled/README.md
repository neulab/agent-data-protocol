# Scale-SWE-Distilled Dataset

## Description

Scale-SWE-Distilled is a large software-engineering agent trajectory dataset released by AweAI-Team as part of the Scale-SWE project. It contains distilled OpenHands-style trajectories from DeepSeek v3.2 for real executable GitHub pull-request tasks.

The dataset focuses on:
- Software engineering bug-fixing and feature tasks sourced from GitHub pull requests
- OpenHands-style agent trajectories with shell execution and file-editing tool calls
- Multi-turn coding workflows with tool observations and final completion signals
